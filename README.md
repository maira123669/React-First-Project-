# ShopSphere Pro

A responsive React e-commerce storefront built with Vite, React Router and Lucide icons.

## Features
- Multi-page storefront, category browsing and product details
- Product search, category filters, price range and sorting
- Cart quantity management and automatic totals
- Wishlist saved in localStorage
- Demo checkout, order confirmation and order history
- About and contact pages
- Responsive desktop, tablet and mobile layouts

## Run locally
1. Install Node.js (LTS).
2. Extract this project folder.
3. Open the folder in VS Code.
4. Open the integrated terminal in the project folder.
5. Run:

```bash
npm install
npm run dev
```

6. Open the local URL printed by Vite (usually http://localhost:5173).

## Important
This is a frontend academic/demo project. Cart, wishlist and order history are stored in the browser's localStorage. Checkout and contact forms are demonstrations only: there is no real payment gateway, authentication server, database, inventory API or email delivery.

Product photos are loaded from Unsplash and therefore require an internet connection.
